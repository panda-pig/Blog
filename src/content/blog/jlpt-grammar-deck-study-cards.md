最初做 `JLPT Grammar Deck` 时，我只想解决一个很具体的问题：日语语法资料很多，但真正到了每天复习的时候，很难快速决定“今天该看什么、哪些已经记住、哪些还会忘”。

现在，这个项目已经不再只是几张好看的语法卡片，而是一套可以真正持续使用的学习系统。最新版本收录 **955 条 N1–N5 语法**，把查询、学习、间隔复习、挖空练习、进度分析和账号同步放进同一条轨道里。

在线版本：[jlpt-grammar-cards.com](https://jlpt-grammar-cards.com)

![JLPT Grammar Deck 最新首页：Guest 模式、N1–N5 入口和可翻面的语法卡片。](/images/blog/jlpt-grammar-deck/jlpt-home.png)

## 现在它是一套完整的学习闭环

最新版本的主线很清楚：

1. 在语法库里搜索或筛选目标语法
2. 阅读意思、接续、例句和易错点
3. 用翻面卡片先回忆，再查看答案
4. 按 Again、Hard、Good、Easy 评价记忆状态
5. 由 SM-2 算法安排下一次复习
6. 通过挖空练习确认自己能否在句子里认出来
7. 在学习数据页查看掌握率、趋势和薄弱语法

这条闭环比“收藏一篇语法说明”更有用，因为每次操作都会留下下一步：看完可以加入学习，打分会进入复习队列，练习结果和复习历史会回到数据页。

## 语法库从资料页升级到 955 条可管理内容

![语法库支持关键词搜索、JLPT 等级、语法场景、学习状态和收藏筛选。](/images/blog/jlpt-grammar-deck/jlpt-grammar-library.png)

语法库目前包含 955 条内容，覆盖 N1 到 N5。每条语法不只是标题和翻译，还包括：

- JLPT 等级与语法场景
- 意思、接续形式和详细解释
- 日文例句与对应翻译
- 易错点、记忆提示和相近语法
- 学习状态、掌握度和收藏状态

搜索和多维筛选仍然是整个系统最重要的入口。比如搜索「わけ」，可以同时看到「わけがない」「わけではない」「というわけではない」等相关表达，再通过等级、场景或学习状态缩小范围。

数据量扩大之后，我也加入了语法去重、旧 ID 重定向和数据审计脚本，避免同一语法因为写法差异被重复计算。对学习产品来说，内容质量和数据一致性与界面同样重要。

## Guest 模式先学习，登录后再同步

现在不注册账号也能直接开始学习。

Guest 模式会把学习进度、收藏、SM-2 状态和复习历史保存在当前浏览器。用户确认这个工具适合自己之后，再登录账号并把本地进度合并到云端，不需要在第一次打开时就做注册决定。

登录后，数据由 Supabase 保存，并通过 Auth 与 RLS 隔离到个人账号。这个设计形成了比较自然的两层体验：

- **本地优先**：打开即可用，没有注册门槛
- **账号同步**：需要跨设备和长期保存时再登录

本地进度导入云端时会合并复习历史，而不是简单覆盖。这是从“演示项目”走向“真实产品”后非常关键的一步。

## 学习卡更快，也更不容易误操作

![学习页先显示正面，翻卡后再展示解释、例句、易错点和四档记忆评分。](/images/blog/jlpt-grammar-deck/jlpt-study-card.png)

学习页仍然保持 Anki 风格：正面只给语法和接续提示，让用户先主动回忆；翻面之后再显示完整说明。

最新版本对操作细节做了不少收敛：

- 评分后立即进入下一张，减少等待感
- 增加“上一张”查看，但上一张保持只读，避免重复计分
- 对快速连点增加提交锁，防止一次评分被记录两次
- 移动端重新压缩统计区域，让卡片和评分按钮更容易触达
- 学习范围会明确显示，避免忘记自己正在学习哪个等级或队列

这些变化看起来不大，却直接影响一天复习几十张卡时的节奏。

## 练习不再只是固定题目，而是自动挖空

![练习页把例句转换成挖空选择题，并显示答题进度与即时反馈。](/images/blog/jlpt-grammar-deck/jlpt-practice.png)

练习页现在会从已有例句自动生成 cloze 挖空题，并提供三种范围：

- **今天练过的语法**：马上检查刚才是否真的记住
- **已经学过的语法**：从个人学习集合里抽题
- **全部语法**：按 JLPT 等级从完整语法库随机练习

系统会从完整语法池生成干扰项，并在作答后显示正确答案、得分和进度。这样练习不再依赖一套手工维护的固定题库，而是可以随着语法内容一起扩展。

## 数据页从“完成百分比”走向复习诊断

![学习数据页展示等级进度、掌握率、评分分布、近期复习和趋势。](/images/blog/jlpt-grammar-deck/jlpt-dashboard.png)

基础数据页会展示今日新学、今日复习、连续天数、等级进度、掌握率、评分分布和近期复习记录。

最新的 Pro 高级分析继续往前走了一步：它不只统计“学了多少”，还会根据更长的复习历史计算：

- 不同复习间隔下的记忆保留率
- 反复出现 Again 或 Hard 的薄弱语法
- 需要优先回看的语法排序
- 长期复习表现，而不是单日打卡数字

这个方向更接近我真正想要的学习反馈：不是用漂亮数字证明自己很努力，而是告诉自己下一轮应该把时间花在哪里。

## 个人语法库、隐藏和收藏都有了账号边界

用户可以收藏默认语法、隐藏暂时不需要的内容，也可以新增自己的私有语法条目。私人条目会进入同一套学习和复习流程，而不是成为与系统割裂的笔记。

随着项目进入正式产品阶段，我也加入了 Free / Pro 权益层。Pro 采用永久权益设计，支付层由配置驱动，当前可以接入 Stripe Checkout，并保留其他支付渠道的订单处理能力。支付状态、订单和用户权益在服务端确认，前端只负责发起和展示结果。

这部分的重点并不是“加一个购买按钮”，而是把账号、订单、支付回调与最终权益打通，让功能边界可以被可靠地执行。

## 技术栈也从原型升级为完整产品架构

当前技术栈已经更新为：

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4 与自定义组件系统
- Supabase PostgreSQL + Auth + RLS
- localStorage Guest 进度与云端合并
- SM-2 复习调度与复习历史分析
- 配置驱动的支付订单与 Stripe Checkout
- Vitest 数据、算法和服务层测试
- Vercel 部署

相比最初版本，最大的变化不是换了框架，而是数据边界变清楚了：公开语法、个人覆盖、私有条目、学习进度、复习历史、订单和权益各自有明确职责。

## 这次升级让我重新理解“学习工具”

一个学习工具真正难做的地方，不是把资料放进页面，而是让内容、行为和反馈形成长期关系。

现在的 `JLPT Grammar Deck` 已经能回答三个连续的问题：

- **我现在学什么？**——语法库、等级与学习队列
- **我什么时候再学？**——SM-2 到期复习
- **我为什么还没记住？**——评分历史、保留率与薄弱语法

从 955 条语法到一条完整的复习曲线，这个项目终于更像一个可以每天打开的产品，而不只是一次界面设计练习。
