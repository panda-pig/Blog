`JLPT Grammar Deck` を作り始めたとき、解決したかったのはひとつの具体的な問題でした。日本語文法の資料は多いのに、毎日の学習では「今日は何を復習するか」「何を覚えたか」「何を忘れそうか」をすぐに判断できません。

現在、このプロジェクトは見栄えのよいカード集ではなく、継続して使える学習システムになりました。最新版には **N1〜N5 の文法 955 項目**が収録され、検索、学習、間隔反復、穴埋め練習、進捗分析、アカウント同期がひとつの流れにつながっています。

公開版：[jlpt-grammar-cards.com](https://jlpt-grammar-cards.com)

![最新版 JLPT Grammar Deck のホーム画面。Guest モード、N1〜N5 の入口、反転できる文法カードが並ぶ。](/images/blog/jlpt-grammar-deck/jlpt-home.png)

## 学習がひとつのループになった

現在の基本フローは明確です。

1. 文法ライブラリで検索・絞り込みを行う
2. 意味、接続、例文、注意点を読む
3. カードをめくる前に答えを思い出す
4. Again、Hard、Good、Easy で記憶状態を評価する
5. SM-2 が次回の復習日を決める
6. 自動生成された穴埋め問題で文中の使い方を確認する
7. 学習データで進捗と弱点文法を見る

読む、評価する、練習するという各操作が、次の復習や分析につながります。

## 955 項目を管理できる文法ライブラリ

![キーワード、JLPT レベル、文法場面、学習状態、お気に入りで絞り込める文法ライブラリ。](/images/blog/jlpt-grammar-deck/jlpt-grammar-library.png)

各項目には、JLPT レベルと文法場面、意味と接続、詳しい説明、日本語例文と訳、注意点、記憶のヒント、類似文法、学習状態を持たせられます。

たとえば「わけ」を検索すると、「わけがない」「わけではない」「というわけではない」などを同じ画面で比較し、レベルや進捗でさらに絞り込めます。

データ量の拡大に合わせて、重複チェック、旧 ID のリダイレクト、文法データの監査スクリプトも追加しました。学習プロダクトでは、UI と同じくらい内容の一貫性が重要です。

## Guest で始め、必要になったら同期する

アカウントを作らなくても、すぐに学習を始められます。

Guest モードでは、進捗、お気に入り、SM-2 の状態、復習履歴を現在のブラウザに保存します。継続利用したいと判断したあとでログインし、ローカル進捗をクラウドへ統合できます。

ログイン後のデータは Supabase に保存し、Auth と RLS でユーザーごとに分離します。

- **ローカル優先**：登録せず、開いてすぐ使える
- **アカウント同期**：端末間利用や長期保存が必要なときにログインする

クラウド移行時には復習履歴を単純に上書きせず、既存データと統合します。

## カード学習は速く、安全になった

![表面で思い出してから、裏面で説明、例文、注意点、4 段階評価を確認する。](/images/blog/jlpt-grammar-deck/jlpt-study-card.png)

Anki 風の基本設計は維持しています。表面では文法と接続だけを見せ、先に能動的に思い出してから裏面を表示します。

最新版では、評価後の即時遷移、読み取り専用の「前のカード」、二重送信防止、モバイルで届きやすい操作配置、現在の学習範囲表示を追加しました。小さな改善ですが、数十枚を続けて復習するときの使い心地を大きく変えます。

## 固定問題ではなく、自動穴埋め練習

![例文から自動生成した穴埋め問題。進捗、得点、回答後のフィードバックを表示する。](/images/blog/jlpt-grammar-deck/jlpt-practice.png)

練習ページは既存の例文から cloze 問題を生成します。対象は次の三つです。

- 今日復習した文法
- これまでに学習した文法
- JLPT レベルで絞り込める全文法

誤答選択肢は文法全体から生成され、回答後には正解、得点、進捗が表示されます。文法データが増えると、練習範囲も一緒に拡張されます。

## 学習量から復習診断へ

![レベル別進捗、定着率、評価分布、最近の復習、学習傾向を示すダッシュボード。](/images/blog/jlpt-grammar-deck/jlpt-dashboard.png)

通常のダッシュボードでは、新規学習、復習数、連続日数、レベル別進捗、定着率、評価分布、最近の履歴を確認できます。

Pro の高度な分析では、より長い復習履歴から次を計算します。

- 復習間隔ごとの記憶保持率
- Again や Hard が繰り返される弱点文法
- 優先して見直す項目
- 単日の打刻ではなく長期の復習傾向

努力量を飾るのではなく、次の時間をどこへ使うべきかを示す分析を目指しています。

## 個人文法、権限、決済

既定文法のお気に入り登録や非表示に加え、個人用の文法項目も作成できます。個人項目も同じ学習・復習フローに入ります。

現在は Free と買い切り型 Pro の権限レイヤーもあります。決済層は設定で切り替えられ、Stripe Checkout へのリダイレクトに対応しています。注文、決済結果、最終的な権限付与はサーバー側で確認します。

## 現在の技術構成

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4 と独自コンポーネント
- Supabase PostgreSQL + Auth + RLS
- localStorage の Guest 進捗とクラウド統合
- SM-2 と復習履歴分析
- 設定駆動の注文処理と Stripe Checkout
- Vitest によるデータ・アルゴリズム・サービス層のテスト
- Vercel デプロイ

最も大きな進歩はフレームワーク変更ではありません。公開文法、ユーザー上書き、個人項目、進捗、復習履歴、注文、権限の責務が分かれたことです。

## 毎日開けるプロダクトへ

現在の `JLPT Grammar Deck` は三つの連続した質問に答えられます。

- **今、何を学ぶか**——ライブラリ、レベル、学習キュー
- **次はいつ学ぶか**——SM-2 の期限付き復習
- **なぜまだ覚えられないか**——評価履歴、保持率、弱点分析

955 項目の文法から復習曲線までつながり、ようやく一度きりの UI 実験ではなく、毎日開ける学習プロダクトになりました。
