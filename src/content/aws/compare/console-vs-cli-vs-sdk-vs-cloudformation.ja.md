## 一言で理解

> Console は GUI、CLI は Command 自動化、SDK は Code への AWS API 組込み、CloudFormation は Infrastructure State の宣言。

## 要点

- Console は探索、学習、単発の手動操作に向く。
- CLI は Script、反復 Command、運用自動化に向く。
- SDK は Application Logic から AWS Service を呼ぶ場合に使う。

## 試験での判断

> CloudFormation は手順列ではなく、Version 管理・Review・再現可能な Infrastructure as Code に使う。
