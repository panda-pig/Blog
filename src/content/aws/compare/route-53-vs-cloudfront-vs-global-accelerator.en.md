## In one sentence

> Route 53 selects destinations through DNS, CloudFront caches content at the edge, and Global Accelerator optimizes global network paths.

## Key points

- Route 53 routing policies and health checks influence which endpoint a name resolves to.
- CloudFront is a CDN for HTTP content, edge caching, TLS, WAF, and private origins.
- Global Accelerator provides static anycast IPs and accelerates TCP/UDP traffic without caching.

## Exam takeaway

> These services can be combined because they solve DNS, content delivery, and network-path problems at different layers.
