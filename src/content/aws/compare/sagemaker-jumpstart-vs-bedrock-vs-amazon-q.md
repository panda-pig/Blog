## 一句话理解

JumpStart 是 SageMaker 的模型起点，Bedrock 是基础模型 API 平台，Amazon Q 是成品助手。

## 核心要点

- 需要在 SageMaker 中部署、微调并控制现成模型 → JumpStart。
- 需要通过托管基础模型 API 构建自己的生成式 AI 应用 → Bedrock。
- 需要企业知识助手或开发助手，不想从零构建产品 → Amazon Q。

## 考试重点

- 先判断题目要“模型”、“应用平台”还是“成品助手”。

## 常见误区

- 不要只凭产品名称选择服务，先确认数据类型、延迟、控制力、运维与成本限制。

## 重点记忆

**JumpStart 找模型，Bedrock 搭应用，Amazon Q 直接当助手。**
