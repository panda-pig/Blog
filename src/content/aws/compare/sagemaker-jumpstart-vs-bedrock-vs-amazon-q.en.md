## In one sentence

JumpStart is a model starting point in SageMaker, Bedrock is a foundation-model API platform, and Amazon Q is a ready-made assistant.

## Key points

- Deploy, fine-tune, and control existing models in SageMaker → JumpStart.
- Build your own generative-AI app with managed foundation-model APIs → Bedrock.
- Need an enterprise or developer assistant without building the product from scratch → Amazon Q.

## Exam focus

- First decide whether the question needs a model, an application platform, or a ready-made assistant.

## Common pitfalls

- Do not choose by product name alone; confirm data type, latency, control, operations, and cost constraints.

## Remember

**JumpStart finds models, Bedrock builds apps, Amazon Q is the assistant.**
