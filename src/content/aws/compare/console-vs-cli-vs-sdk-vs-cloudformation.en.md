## In one sentence

> Console is graphical, CLI automates commands, SDK integrates AWS APIs into code, and CloudFormation declares infrastructure state.

## Key points

- Use Console for exploration, learning, and occasional manual operations.
- Use CLI for scripts, repeatable commands, and operational automation.
- Use SDK when application logic must call AWS services.

## Exam takeaway

> Use CloudFormation for versioned, reviewable, repeatable infrastructure as code rather than sequences of manual steps.
