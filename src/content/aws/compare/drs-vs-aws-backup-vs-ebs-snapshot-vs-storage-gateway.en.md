## In one sentence

> DRS recovers servers, AWS Backup governs backups, EBS snapshots protect volumes, and Storage Gateway provides hybrid storage interfaces.

## Key points

- AWS DRS continuously replicates servers for low-RTO failover and later failback.
- AWS Backup centralizes schedules, retention, vaults, and policy across supported resources.
- An EBS snapshot is a point-in-time volume copy and not a complete disaster-recovery process by itself.

## Exam takeaway

> Storage Gateway exposes file, volume, or tape interfaces for long-term hybrid access rather than orchestrating server recovery.
