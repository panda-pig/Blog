## 一言で理解

JumpStart は SageMaker のモデル起点、Bedrock は基盤モデル API、Amazon Q は完成済みアシスタントです。

## 要点

- SageMaker で既存モデルをデプロイ・微調整・制御 → JumpStart。
- 基盤モデル API で独自の生成 AI アプリを構築 → Bedrock。
- ゼロから作らず企業知識助手や開発助手を利用 → Amazon Q。

## 試験ポイント

- まず「モデル」「アプリ基盤」「完成済み助手」のどれが必要か判断します。

## よくある誤解

- 製品名だけで選ばず、データ型、遅延、制御性、運用、コスト制約を確認します。

## 重要ポイント

**JumpStart はモデル、Bedrock はアプリ構築、Amazon Q は助手。**
