## 役割の比較

| Tool / 概念 | 主な質問 | 代表的な動作 |
| --- | --- | --- |
| Billing Dashboard | 現在の請求と支払いは？ | 料金、Invoice、Payment を確認 |
| AWS Budgets | 実績・予測が目標を超えるか？ | しきい値通知と制御 Action |
| Cost Explorer | どこに費用がかかり、傾向は？ | Filter、Group、Report、Forecast |
| Pricing Calculator | 新しい構成の予想費用は？ | 導入前見積もり |
| Cost Allocation Tags | どの Team / Project の費用か？ | Cost の配賦と分析 |
| Organizations | 複数 Account をどう管理・請求するか？ | Consolidated Billing、OU、SCP |
| Compute Optimizer | Resource Spec は適切か？ | Right Sizing 候補 |
| Trusted Advisor | 改善できる Best Practice は？ | Cost、Security、Performance、Resilience、Quota |
| Support Plans | AWS からどの支援を受けられるか？ | Case Response、TAM、Proactive Guidance |
| Marketplace / APN | 製品購入か Partner 探しか？ | 製品は Marketplace、専門家は APN |

## 試験の注意点

Budgets は初期状態で全 Resource を停止しません。Pricing Calculator は実請求を読みません。Cost Explorer は Real-Time Performance Monitoring ではなく、Consolidated Billing は Identity や Resource を統合しません。

## 重要ポイント

**Billing は確認、Budgets は Guardrail、Explorer は分析、Calculator は見積もりです。**
