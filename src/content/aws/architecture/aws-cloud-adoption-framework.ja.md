## 6 つの Perspective

| Perspective | 主な観点 |
| --- | --- |
| Business | Value、成果、戦略との整合 |
| People | 組織、Skill、Culture、Change |
| Governance | Risk、Compliance、投資、Governance |
| Platform | Cloud Platform、Architecture、Data、Engineering |
| Security | Identity、Detection、Infrastructure、Data Protection |
| Operations | 運用、Observability、Incident、継続的改善 |

CAF は組織変革、3 段階移行は Assess → Mobilize → Migrate & Modernize、Well-Architected は 6 本の柱による Workload Review を扱う。CAF 自体は Server や Data を移行しない。
