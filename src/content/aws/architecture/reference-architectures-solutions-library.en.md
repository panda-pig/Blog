## In one sentence

Architecture Center teaches design patterns, while Solutions Library provides vetted solutions and implementation material.

## Core summary

Define requirements, select a fitting pattern and reference architecture, read the implementation guide, deploy in a test environment, and validate normal and failure paths.

## Study points

- A pattern is a reusable idea, not a deployment file.
- A reference architecture explains a service combination but does not replace permissions, capacity, data protection, or testing.
- Each solution provides a different set of code and templates.
- Review the running workload again with Well-Architected and record milestones.

## Common pitfalls

- Vetted does not mean automatically suitable or compliant for your workload.
- A successful template deployment does not prove cost, production readiness, or disaster recovery.

## Key memory

**Patterns explain ideas, references explain combinations, guides explain implementation, and validation proves fitness.**
