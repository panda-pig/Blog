## 与其他框架的区别

- **CAF** 面向组织转型和云就绪能力。
- **三阶段迁移** 描述 Assess → Mobilize → Migrate & Modernize 的项目顺序。
- **Well-Architected Framework** 用六大支柱评审具体工作负载。

CAF 不搬运服务器或数据；题目强调组织、人员、治理和运营能力时优先想到 CAF。
