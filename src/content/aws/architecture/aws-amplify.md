## 一句话理解

为 Web/Mobile 团队提供前端构建托管、Git 驱动持续部署和云后端连接的一体化体验。

## 核心作用

- 从代码仓库构建并发布前端，支持分支预览和自动部署。
- 连接认证、API、数据、存储和函数等后端能力。
- 提供前端组件、客户端库和多环境开发工作流。

## 考试重点与误区

- 前端团队、快速全栈交付、Git 驱动托管 → Amplify。
- AppSync 是 GraphQL API；Amplify 可以创建或消费 AppSync，但两者职责不同。
- S3 + CloudFront 是更底层的静态内容托管与分发组合。
- Amplify 不是单一数据库，也不代表无需管理 IAM、认证、环境隔离和数据权限。

## 重点记忆

**Amplify 管 Web/Mobile 开发体验；AppSync 管 GraphQL API。**
