AWS Well-Architected Framework = AWS 設計ベストプラクティス

## 6 本の柱

1. **Operational Excellence**：運用を観測・自動化し、継続的に改善する。
2. **Security**：Identity、Infrastructure、Data を保護し、Detection と Response を行う。
3. **Reliability**：Failure から復旧し、動的に Scale して需要を満たす。
4. **Performance Efficiency**：適切な Resource を選び、需要に合わせて進化させる。
5. **Cost Optimization**：不要な支出をなくし、Value に合わせて最適化する。
6. **Sustainability**：Resource の無駄と環境負荷を減らす。

Framework は Best Practice 体系、**Well-Architected Tool** は Review、Milestone、改善項目を記録する Tool。CAF は組織変革、Trusted Advisor は Account Level の自動 Check を扱う。
