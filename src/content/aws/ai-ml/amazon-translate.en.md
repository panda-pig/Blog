## In one sentence

A neural machine-translation service for translating text between languages.

## Key points

- It fits websites, localized content, multilingual support, and document translation.
- Both input and output are text; audio must be transcribed first.
- Translate changes the language; Comprehend analyzes the meaning.

## Exam focus

- Choose Amazon Translate for multilingual text translation.

## Common pitfalls

- Do not choose by product name alone; confirm data type, latency, control, operations, and cost constraints.
