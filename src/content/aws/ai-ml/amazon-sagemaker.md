## 一句话理解

用于准备数据、构建、训练、部署和监控自定义机器学习模型的托管平台。

## 核心要点

- 覆盖数据准备、训练、调参、实验、端点部署、批量推理和模型监控。
- Training 从历史数据学习模型；Inference 使用已训练模型预测新数据。
- 适合使用企业自有数据构建预测、分类、推荐或异常检测模型。

## 考试重点

- “构建、训练和部署自己的模型”优先选择 SageMaker。
- 预训练 AI API 选择 AWS AI Services；托管基础模型 API 选择 Bedrock。

## 常见误区

- 不要只凭产品名称选择服务，先确认数据类型、延迟、控制力、运维与成本限制。

## 重点记忆

**自己的数据 + 自定义模型 + 完整 ML 生命周期 = SageMaker。**
