## 一句话理解

查找、购买、订阅和部署第三方 AMI、容器、SaaS、数据、AI/ML 产品与专业服务，符合条件的费用可整合到 AWS 账单。

## 常见误区

- Marketplace 是外部产品交易目录；Service Catalog 是企业内部批准的标准产品目录。
- Marketplace 买产品；APN 找咨询、实施、迁移或托管伙伴。
- 第三方产品仍有自己的许可、网络、数据处理和支持责任。

## 重点记忆

**买第三方现成软件、数据和服务 → AWS Marketplace。**
