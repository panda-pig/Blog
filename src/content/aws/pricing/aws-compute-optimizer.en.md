## One-line summary

Use historical metrics and configuration data to generate candidate sizes, performance risks, and estimated savings for supported resources.

Recommendations are not automatic changes. Validate the observation period, peak demand, memory data, licensing, availability, and performance risk before implementation. Compute Optimizer recommends sizes; Auto Scaling changes capacity count; Cost Explorer analyzes spend; Trusted Advisor checks broader categories.

## Key takeaway

**Utilization data plus right-sizing candidates and estimated savings means Compute Optimizer.**
