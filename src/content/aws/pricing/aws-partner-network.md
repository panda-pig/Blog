## 一句话理解

由咨询、技术和服务企业组成的 AWS 全球合作伙伴生态，用于寻找迁移、架构、安全、数据、AI/ML、行业方案和托管服务专家。

## 常见误区

- APN 不是软件产品目录，也不是 AWS 内部员工团队。
- Marketplace 买产品；APN 找外部合作伙伴；Professional Services 是 AWS 自己的专业服务团队。
- 引入伙伴可以补足能力，但客户仍需明确合同、数据访问、安全责任和交付验收。

## 重点记忆

**Marketplace 买产品，APN 找专家。**
