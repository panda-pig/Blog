## In one sentence

> Encrypted IPsec connectivity between an on-premises network and a VPC or Transit Gateway over the internet.

## Key points

- The AWS side uses a Virtual Private Gateway or Transit Gateway; the customer side uses a Customer Gateway.
- Each VPN connection normally provides two tunnels for redundancy.
- Routing can use static routes or BGP depending on the configuration.

## Exam takeaway

> VPN is quicker and internet-based; Direct Connect provides dedicated connectivity and more consistent performance.
