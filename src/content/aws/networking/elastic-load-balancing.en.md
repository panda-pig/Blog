## In one sentence

> Distributes traffic across healthy targets to improve availability and scale application entry points.

## Key points

- ALB operates at Layer 7 for HTTP/HTTPS routing by host, path, and application rules.
- NLB operates at Layer 4 for very high-performance TCP/UDP/TLS traffic and static IP needs.
- GWLB inserts and scales virtual network appliances.

## Exam takeaway

> Load balancing distributes traffic; Auto Scaling changes target capacity.
