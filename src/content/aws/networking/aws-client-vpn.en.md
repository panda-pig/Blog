## In one sentence

> A managed remote-access VPN that connects individual users securely to AWS and connected networks.

## Key points

- It is designed for user devices, unlike Site-to-Site VPN for whole networks.
- Authentication can use certificates, Active Directory, or federated identity options.
- Authorization rules, routes, target networks, and security groups determine reachable resources.

## Exam takeaway

> The service endpoint is managed, but identity, authorization, routing, and client configuration remain customer responsibilities.
