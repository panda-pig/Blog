## Core role

- Plans and tracks servers, applications, and migration waves in one view.
- Aggregates status from multiple migration tools to expose blockers and progress.
- Related experiences are increasingly integrated into AWS Transform, while older questions may still use the Migration Hub name.

Migration Hub is a **management and visualization layer**, not a replication engine. Use Transform MGN for servers, DMS for databases, and DataSync or Transfer Family for files.
