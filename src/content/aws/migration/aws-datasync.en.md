## In one sentence

> Automates high-speed online transfer and synchronization of files or objects between on-premises, AWS, and other clouds.

## Key points

- Create source and destination locations, then use a task to define transfer, metadata, verification, and scheduling behavior.
- On-premises or self-managed storage often uses a DataSync agent; requirements depend on source and destination.
- DataSync moves or synchronizes data; Storage Gateway provides long-term hybrid storage interfaces.

## Exam takeaway

> Use Snow Family when network transfer is unsuitable, Transfer Family for managed file-transfer protocols, and DMS for databases.
