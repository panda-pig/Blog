## 重点记忆

AWS Migration Hub = 迁移跟踪中心

## 核心作用

- 将服务器、应用和迁移波次放在统一视图中规划与跟踪。
- 聚合多个迁移工具的状态，帮助识别阻塞项和项目进度。
- 相关迁移体验正逐步整合进 AWS Transform；旧题仍可能使用 Migration Hub 名称。

## 考点

Migration Hub 是**管理与可视化层**，不是复制引擎。服务器块级复制看 AWS Transform MGN；数据库看 DMS；文件看 DataSync 或 Transfer Family。
