## 收集与使用

- 无代理发现可快速盘点服务器配置与使用率；代理式发现可获得进程、网络连接和依赖关系等更细信息。
- 发现数据用于识别应用边界、依赖链和迁移波次，不直接迁移工作负载。
- 典型顺序是收集数据、进行应用分组、结合 Migration Evaluator 建立商业案例，再选择迁移策略与执行服务。

## 易混淆

- **Migration Hub**：统一查看迁移项目和进度。
