## In one sentence

Extends a VMware SDDC onto AWS while preserving familiar VMware software and operational tools.

## Core summary

Connects on-premises VMware with vSphere, vSAN, and NSX on AWS for extension, migration, hybrid cloud, and disaster recovery.

## Study points

- Preserving the VMware platform aligns with Relocate.
- For low-downtime rehosting to native EC2, consider MGN.
- Native AWS services still require networking, IAM, and encryption configuration.
- Disaster recovery still needs replication, RPO/RTO, procedures, and testing.

## Common pitfalls

- A VMware source does not force VMware Cloud as the target.
- Platform extension and continuous block replication solve different goals.

## Key memory

**Preserve VMware operations with VMware Cloud; move to native EC2 with MGN or image import.**
