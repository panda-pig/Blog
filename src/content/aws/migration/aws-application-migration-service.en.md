## Name and workflow

AWS Application Migration Service was renamed **AWS Transform MGN** in June 2026. Core capabilities, APIs, and the replication engine remain continuous, while older questions may use MGN or the former name.

1. Install an agent and continuously replicate block-level changes to an AWS staging area.
2. Launch test instances and validate the application, network, performance, and dependencies.
3. Schedule a cutover, complete final synchronization, and launch cutover instances.
4. Validate and finalize, retaining a rollback plan when needed.

MGN migrates servers and applications; DMS migrates databases; DataSync transfers file and object data.
