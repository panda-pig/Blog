## 一言で理解

> 必要な資源特性で EC2 ファミリーを選び、安定性と中断許容度で料金モデルを選択する。

## 要点

- General Purpose はバランス型、Compute / Memory / Storage / Accelerated は特定のボトルネック向け。
- On-Demand は短期または予測困難で、長期契約が不要な用途に合う。
- Savings Plans / Reserved Instances は安定負荷でコミットメントと引き換えに割引を得る。

## 試験での判断

> Spot は中断可能で耐障害性のある処理、Dedicated 系はテナンシーやライセンス要件向け。
