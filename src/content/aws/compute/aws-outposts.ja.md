## 一言で理解

> 低遅延やデータ配置要件のため、顧客拠点に設置して一部 AWS サービスを実行する AWS 管理インフラ。

## 要点

- AWS のインフラ、API、運用モデルをオンプレミス拠点へ拡張する。
- 極めて低いローカル遅延、現地処理、特定のデータ配置要件に対応する。
- 顧客は設置場所、電力、冷却、接続を提供し、AWS が Outposts 基盤を管理する。

## 試験での判断

> Outposts はハイブリッド基盤であり、AWS Region やクラウド全体の代替ではない。
