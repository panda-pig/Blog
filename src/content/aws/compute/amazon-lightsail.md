## 一句话理解
把虚拟服务器、存储、IP、DNS 和部分网络能力打包成简单、价格可预测的入门云服务。
## 核心作用
- 以固定套餐快速创建 VPS。
- 降低完整 AWS 控制台和架构设计的复杂度。
- 提供适合小型工作负载的一站式体验。
## 适用场景
- WordPress、博客、小型企业网站。
- 低流量 Web 应用。
- 开发测试和个人学习项目。
- 希望使用可预测月费的简单服务器。
## 与 EC2 的区别

| 维度 | Lightsail | EC2 |
| --- | --- | --- |
| 配置体验 | 简化、一站式 | 灵活、组件丰富 |
| 定价 | 套餐式、容易预测 | 多种计费模型 |
| 架构复杂度 | 适合简单项目 | 适合复杂和大型架构 |
| 控制与扩展 | 较有限 | 更强 |

## Cloud Practitioner 考点
题目强调“小型网站、快速上手、简单套餐、固定月费”时考虑 Lightsail。
## 常见误区
- Lightsail 不是 EC2 的全面替代品。
- 复杂网络、多服务集成和精细扩展通常更适合完整 AWS 服务组合。
## 重点记忆
Lightsail = AWS 的简化版 VPS 套餐。
