## 一言で理解

> アプリケーションコードをアップロードすると一般的な AWS インフラを構築するマネージドアプリケーションデプロイサービス。

## 要点

- コードをアップロードすると EC2、Load Balancer、Auto Scaling などを作成・運用する。
- PaaS に近い体験だが、基盤リソースは確認・設定できる。
- すべてのリソースを手作業で設計せず、一般的な Web アプリを素早く配置したい場合に向く。

## 試験での判断

> CloudFormation は汎用インフラ、Beanstalk はアプリケーション環境の配置が中心。
