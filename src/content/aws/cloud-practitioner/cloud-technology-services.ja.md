## 一言で理解

製品名だけでなく、Compute、Storage、Database、Networking、Analytics、AI を用途で識別します。

## 要点

- S3 はオブジェクトストレージとデータレイク、Redshift は DWH、Athena は S3 を SQL で検索します。
- Glue Data Catalog はメタデータ、Glue ETL は変換、Kinesis Streams は取り込み、Firehose は配信です。
- 事前学習済み機能は AWS AI Services、独自モデルは SageMaker、基盤モデル API は Bedrock です。
- RDS/Aurora はリレーショナル取引、DynamoDB は大規模・低遅延 Key-Value、キャッシュは DAX または ElastiCache です。

## 試験ポイント

- Polly は読み上げ、Transcribe は文字起こし、Translate は翻訳、Comprehend は文理解、Textract は文書抽出、Rekognition は画像認識。
- Multi-AZ は高可用性、Read Replica は読み取り拡張、Query は通常 Scan より効率的です。

## よくある誤解

- 製品名だけで選ばず、データ型、遅延、制御性、運用、コスト制約を確認します。

## 重要ポイント

**用途からサービスを選び、役割を分けて似た選択肢を除外します。**
