## 一言で理解

グローバルインフラ、責任共有、セキュリティ、主要サービス、料金、サポートを軸に最終復習します。

## 要点

- 順序：グローバルインフラと責任共有 → IAM/セキュリティ → EC2/S3/RDS/VPC/Lambda → 料金ツール → サポート。
- SQL・JOIN・トランザクション → RDS/Aurora、Key-Value・Serverless・低遅延 → DynamoDB。
- Multi-Region Active-Active → DynamoDB Global Tables、DynamoDB のマイクロ秒キャッシュ → DAX。
- 複雑 JSON/MongoDB 互換 → DocumentDB、関係グラフ → Neptune、移行 → DMS、異種変換 → SCT。

## 請求とサポートの1分確認

- 現在の請求と支払い → Billing Dashboard、実績・予測のしきい値 → AWS Budgets。
- 過去の Cost、傾向、Forecast → Cost Explorer、導入前見積もり → Pricing Calculator。
- 複数 Account の一括支払いと対象割引の集約 → Organizations Consolidated Billing。
- Project、部門、Environment への帰属 → Cost Allocation Tags。
- Right Sizing 推奨 → Compute Optimizer、幅広い Best Practice → Trusted Advisor。
- 第三者 Software、AMI、SaaS → Marketplace、AWS Partner → APN。
- Basic に Technical Case SLA はなく、Enterprise は TAM を重視します。応答目標は解決保証ではありません。

## 試験ポイント

- CLF は実装詳細より、サービス用途、責任境界、クラウドの価値を重視します。

## よくある誤解

- 製品名だけで選ばず、データ型、遅延、制御性、運用、コスト制約を確認します。

## 重要ポイント

**インフラ、責任、セキュリティ、主要サービス、料金とサポートで仕上げます。**
