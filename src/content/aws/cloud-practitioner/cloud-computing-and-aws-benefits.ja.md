## 一言で理解

> 固定的な先行投資ではなく、On-Demand の IT Resource と従量課金を利用する。

## 要点

- Resource を迅速に用意し、Capital Expense を Variable Expense へ変える。
- Economies of Scale、Global Reach、Elasticity、迅速な Experiment の利点を得る。
- 需要に合わせて Resource を拡縮し、Capacity の過不足を減らす。

## 試験での判断

> Cloud の利点を得るには Architecture、Governance、Security、Cost Management が必要。
