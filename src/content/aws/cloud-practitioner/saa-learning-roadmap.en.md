## In one sentence

A staged route from cloud foundations and domain study to question review and exam preparation.

## Core summary

Build cloud fundamentals first, then study compute, storage, databases, networking, security, integration, monitoring, and architecture.

## Study points

- Record wrong answers, lucky guesses, timeouts, and high-uncertainty questions.
- Write mechanisms back to service notes and cross-service differences to comparison notes.
- Use the four Exam Guide domains to find gaps and practice complete constraints.
- After SAA, choose a path based on the work you want to do; certifications have no mandatory order.

## Common pitfalls

- This is a capability checklist, not a public progress tracker.
- Course completion, practice scores, and an AWS certification are separate outcomes.

## Key memory

**Build foundations, study by domain, use questions to expose gaps, and write the learning back.**
