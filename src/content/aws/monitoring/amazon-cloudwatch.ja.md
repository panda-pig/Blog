## 一言で理解

> Metric、Log、Alarm、Dashboard、自動アクションを提供する AWS の監視・可観測性サービス。

## 要点

- Metric は数値時系列を追跡し、CloudWatch Logs は Log Event を保存・検索する。
- Alarm は Metric を評価し、SNS 通知や自動アクションを実行できる。
- Dashboard は複数の Resource / Application の運用状況をまとめる。

## 試験での判断

> CloudWatch は監視、CloudTrail は API 監査、Config は Resource Configuration の追跡を担当する。
