## One-line summary

Publish approved standardized cloud products in a catalog for controlled self-service deployment.

## Core capabilities and use cases

- A portfolio groups products and defines who may use them.
- Products are commonly backed by CloudFormation templates and can represent complete environments.
- Administrators publish versions and apply launch or template constraints.
- Authorized users launch provisioned products without receiving unrestricted infrastructure permissions.
- Typical uses include standardized test environments, three-tier stacks, instance sizes, networks, and tags.

## Exam focus and common pitfalls

- Approved product catalog plus controlled self-service deployment points to Service Catalog.
- Marketplace is a third-party software and data marketplace; Control Tower governs multi-account landing zones.
- Service Catalog defines what may be deployed, while License Manager tracks license usage.

## Key takeaway

**Turn approved templates into products so users can deploy them through controlled self-service.**
