## One-line summary

Continuously collect and organize audit evidence from the customer AWS environment using audit frameworks.

## Core capabilities and use cases

- Uses prebuilt or custom frameworks to organize controls, control sets, and evidence.
- An assessment defines scope and maps controls to AWS evidence sources.
- Evidence is collected continuously from services such as Config, CloudTrail, and Security Hub.
- Teams review assessment progress and produce reports for auditors.
- It reduces evidence-gathering work but does not certify compliance or automatically remediate gaps.

## Exam focus and common pitfalls

- Automatic evidence collection organized by an audit framework points to Audit Manager.
- Artifact provides AWS reports and agreements; CloudTrail records API activity; Config evaluates configuration rules.
- Human review, remediation, and external audit judgment are still required.

## Key takeaway

**Audit framework plus continuous evidence collection and assessments means AWS Audit Manager.**
